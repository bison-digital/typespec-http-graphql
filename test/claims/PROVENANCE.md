# The claims matrix: where its expectations come from

`claims.test.ts` holds the README to rows written out by hand, and `extras/expected.graphql` is the
schema a person would write for `extras/main.tsp`. Both are oracles, so neither may be written from
what the emitter produces.

## Sources

| what                                    | written from                                                                                                                        |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| each row's `data`, `errors` and `calls` | the README sentence the row quotes, and design.md's tables where the README names no code (a 5xx's reason phrase, a masked error)   |
| the handler inputs a row expects        | the README's "the handler receives exactly what the REST route's handler would": wire keys, defaults applied, an omitted key absent |
| `extras/expected.graphql`               | design.md's rules (§ Names, § Arguments, § Results, § Types) and `test/idiom/PROVENANCE.md`'s sources for the shared conventions    |

Neither `src/` nor any emitted file was read to write them. Where a row first disagreed with the
emitter, the disagreement is recorded below with which side was wrong and why.
