# Oracles

For each thing this emitter writes or decides, the independent thing it must agree with, the arm
that compares them, and the defect that arm was shown to catch.

**An artefact with no row here is a pair nobody is comparing.** Adding a suite means adding a row,
then planting a defect and seeing something go red. `test/documentation.test.ts` fails while a suite
has no row, or a row names a suite that is gone.

## Planting a defect

Stage everything (`git add -A`), plant the defect in the module the row names, run the arm and see
it fail on the assertion the row describes, revert, and confirm `git diff --exit-code` exits 0. A
plant that leaves the arm green means the arm is not grading what its row says, and the row is
wrong until it is fixed.

The defect each row names is the one planted when its arm was built.
